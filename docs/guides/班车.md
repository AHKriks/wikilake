# 班车

学校班车往返于 **云谷**、**云栖**、**铜鉴湖** 三个校区之间，工作日与周末班次不同。往返校外的公交、地铁与打车攻略见 [交通](/guides/交通)。

:::tip[实时信息与临时调整]

- [点击查看班车实时信息](https://security.zjwsvip.com/#/h5shuttleRoute/1906876984879099905)
- 法定假期 / 调休日班车安排，以学校邮件通知为准。

:::
